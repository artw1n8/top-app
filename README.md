# Top App (Next.js & TypeScript)

A web application for product reviews and ratings, built with **Next.js (App Router)** and **TypeScript**. 

**Note:** This project is currently in active development. It is being built as part of an advanced frontend course by [PurpleSchool](https://purpleschool.ru/course/nextjs).

## Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** CSS Grid & Modules
- **Animations:** Framer Motion (planned)
